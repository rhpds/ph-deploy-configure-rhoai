= {lab_name}

Welcome to the *{rhoai} {rhoai_version} Deploy & Configure* workshop. This hands-on lab takes you
end-to-end: from installing {rhoai} on {ocp} through serving, governing, scaling, and observing large
language models — all on a *CPU-only* cluster, so you can complete every exercise without a GPU.

== What you'll learn

Across seven modules you will:

* *Install {rhoai-short}* on a connected cluster, and mirror it for a disconnected / air-gapped install
* *Configure the model-serving platform* (KServe single-model serving + a vLLM runtime)
* *Serve a model with vLLM* and query it through the OpenAI-compatible API
* *Govern access with {maas}* — subscriptions, API keys, and token rate limiting
* *Scale with distributed inference* using llm-d and the Workload Variant Autoscaler
* *Observe* vLLM engine metrics and MaaS token-usage telemetry

== Who this is for

{ocp}/platform administrators and MLOps engineers who need a repeatable, verifiable path to stand up
and operate {rhoai} {rhoai_version}.

*Experience level*: Intermediate to advanced

*Estimated time*: 3-4 hours (modules are independent enough to run in a single sitting or across sessions)

== Prerequisites

* Cluster-admin on an {ocp} {ocp_version} cluster
* Ability to install operators: {rhcl} (Kuadrant/Authorino), cert-manager, Leader Worker Set
* No object storage required — model weights are pulled from public OCI modelcar images, and the
  MaaS PostgreSQL database is deployed in-cluster during Module 5

== A note on hardware and Technology Preview

* *CPU-only*: Every module runs without a GPU, using the `{cpu_model}` model.
  GPU-specific tuning is described conceptually and can be enabled later.
* *Technology Preview*: Module 5 (vLLM-on-MaaS) exercises a Technology Preview feature, clearly
  flagged; APIs and behaviour may change and it is not supported for production use.
* *CPU vs GPU autoscaling*: Module 6 scales llm-d with the Custom Metrics Autoscaler (KEDA) on CPU,
  and covers the GPU-only Workload Variant Autoscaler as reference for a future GPU cluster.
