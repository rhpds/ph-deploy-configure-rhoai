= Getting Connected

In this activity you will log into {ocp}, open a terminal, and clone the workshop manifests so the
`oc apply` commands in later modules resolve correctly.

== Log in to OpenShift (web console)

. Open the OpenShift console:
+
{openshift_console_url}

. Log in with your lab credentials:
+
*Username:* `{openshift_cluster_admin_username}`
+
*Password:* `{openshift_cluster_admin_password}`

== Log in from the terminal

. Switch to the *Terminal* tab (or use the web terminal in the right panel).

. Log in to the cluster API with the `oc` CLI:
+
[source,bash,role="execute",subs="attributes"]
----
oc login {openshift_api_url} -u {openshift_cluster_admin_username} -p {openshift_cluster_admin_password} --insecure-skip-tls-verify=true
----

=== Verify

* `oc whoami` returns `{openshift_cluster_admin_username}`:
+
[source,bash,role="execute"]
----
oc whoami
----
* `oc version` prints a Server Version of `{ocp_version}`:
+
[source,bash,role="execute"]
----
oc version
----

== Clone the workshop manifests

The Kustomize manifests referenced throughout this guide live in the workshop repository.

[source,bash,role="execute",subs="attributes"]
----
git clone {repo-url} ~/rhoai-deploy-configure
cd ~/rhoai-deploy-configure
ls manifests
----

=== Verify

* The `manifests/` directory lists the per-phase folders (`01-install`, `02-disconnected`, ...).

[NOTE]
====
All `oc apply -k manifests/...` paths in this guide are relative to the repository root
(`~/rhoai-deploy-configure`). Make sure you are working from that directory.
====

== Next steps

You are logged in on both the console and the CLI, and the manifests are cloned. Continue to
xref:module-01-install-connected.adoc[Module 1] to install {rhoai-short} on the cluster.
